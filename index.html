EASY CUSTOMIZATION

What You Can Change

Branding

Edit the site name, subtitle, colors, groups, and default unit price inside customize.js.

Database

Paste your Firebase values into firebase-config.js. Everyone using the site will then see the same records.

Hosting

Upload these files to GitHub Pages, Firebase Hosting, or another static host.

Permissions

The included starter rules allow shared access. Add Firebase Authentication before using private or real-world information.
